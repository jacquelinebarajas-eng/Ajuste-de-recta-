# Ajuste-de-recta-
A continuación se presentan los códigos de los cuatro modelos del problema de optimización de ajuste de una recta:
* Modelo 1 (Mínimos cuadrados)
* Modelo 2 (Mínimizando el error)
* Modelo 3 (Mínimizando la suma de los errores)
* Modelo 4 (Mínimizando el máximo de los errores)

Para ejecutar los modelos 2,3 y 4, se deben usar solver, solver1 y solver2
